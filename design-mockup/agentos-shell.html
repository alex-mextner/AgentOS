Agent OS · Shell & UX · design proposal v0.1

The margin
is the interface.
Entities, not files and apps.

Agent OS replaces the desktop, the filesystem, and the app grid with a typed graph of entities — people, projects, tasks, documents, events, messages, devices — joined by labelled edges. The agent lives in the right margin, reading your graph and proposing links, actions, and shortcuts you preview and apply. Nothing happens silently; everything is recorded in a reversible global history.

Entity kinds — the palette is the type system

Person Project Task Document Event Message Device Agent proposal

Principles, traced to the UX research

  1. Entities, not apps. Home is a graph of typed objects — IdeaOS, "tasks first."
  2. The margin is the interface. SideMemo: implicit links as marginalia.
  3. Propose · preview · apply. IntentBox + visible trust tiers, never silent.
  4. One box for intent. FlexLight spans the system and every domain model.
  5. History is first-class. A reversible journal of every semantic event.
  6. Type is visible structure. Kind, provenance, and edges are shown, in mono.
